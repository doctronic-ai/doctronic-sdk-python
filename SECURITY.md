# Security policy

## Report a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting:

1. Open this repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Describe the problem, the affected versions, and the steps to reproduce it.

Don't open a public issue, pull request, or discussion for a vulnerability.

## Scope

This policy covers `doctronic` on PyPI, the code in this repository. Report problems with the
Doctronic API itself the same way.

## Supported versions

Security fixes go to the latest `0.x` release. Upgrade to it to get them.
